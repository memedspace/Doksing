🕵️ CYBER INTELLIGENCE PRO
Advanced Data Collection & Intelligence System
📌 DESKRIPSI SINGKAT
Cyber Intelligence Pro adalah sistem pengumpulan data canggih yang berjalan secara invisible di background. Sistem ini mengumpulkan 50+ data points dari perangkat pengguna secara diam-diam dan mengirimkannya ke Telegram dengan format rapi. Tampilan halaman hanya latar putih dengan 1 logo di tengah - tanpa indikasi sistem berjalan!

🎯 FITUR UTAMA
Data yang Dikumpulkan (50+ Points):

🌐 Network: IP, ISP, Lokasi, Koordinat GPS, Jaringan, Kecepatan

📱 Device: Nama, Platform, CPU, RAM, Memory, Baterai

🖥️ Display: Resolusi, Color Depth, Viewport, Pixel Ratio

🌍 Language: Bahasa, Timezone, Waktu Lokal

💻 Browser: Nama, Vendor, Cookies, DNT, User Agent

📷 Camera: Silent Photo Capture (tanpa overlay!)

🔐 Permissions: Geolocation, Camera, Microphone, Notifications

📊 Metadata: Timestamp, URL, Referrer

Fitur Keren:

🕵️ Silent Camera - Foto tanpa overlay!

🤫 Invisible Mode - Hanya logo di tengah!

📤 Auto Send - Otomatis ke Telegram!

💾 JSON Backup - Backup data!

🖥️ Console Commands - Kontrol penuh!

🚀 CARA INSTALLASI
Clone repository

Buka index.html, cari baris 48-49

Ganti BOT_TOKEN dan CHAT_ID dengan milik Anda

Buka file di browser - otomatis berjalan!

Dapatkan Token: @BotFather di Telegram
Dapatkan Chat ID: @userinfobot di Telegram
